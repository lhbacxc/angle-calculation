## 已确认的实现限制

| 问题 | 当前事实 | 修改位置 |
|------|----------|----------|
| 运算丢失小数秒 | `normalize()` 使用 `seconds.round()`；四则运算均调用它，`15″ ÷ 2` 实测为 `0°00′08″` | `../lib/models/angle.dart` |
| 模型可显示小数，但运算不保留 | 直接由 `Angle.fromDecimal(7.5 / 3600)` 创建时显示 `0°00′07.50″` | `../lib/models/angle.dart` |
| 历史复用界面未接通 | 卡片 `Navigator.pop` 返回 `entry.expression`；计算器没有等待并处理返回值，未调用 `loadFromHistory(result)` | `../lib/screens/history_screen.dart`、`../lib/screens/calculator_screen.dart` |
| 角度范围没有固定校验 | 实测 `Angle.fromDecimal(720)` 得到 `720°00′00″`，没有限制到 ±360° | `../lib/models/angle.dart` |
| 显示与旧示例格式不同 | 分、整数秒补足两位；十进制度显示六位小数并带 `°` | `../lib/models/angle.dart` |

导出实现调用 `getExternalStorageDirectory()`，写入其 `Exports/` 子目录，不是公共 Downloads。服务未检查存储权限，但启动入口仍先请求 storage，拒绝后尝试 photos。Android 文件管理器能否访问应用专属目录取决于系统和工具，应实机核验。

- `../README.md` 保留用户快速入口；`../AGENTS.md` 存放执行规则与文档入口。
